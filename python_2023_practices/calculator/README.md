# Calculator

A simple command-line calculator written in Python.

## Description

The program takes two numbers and an arithmetic operation from the user, then calculates and displays the result.

### Supported Operations

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division
* `//` Floor division

## Features

* Supports positive and negative numbers
* Supports decimal numbers
* Validates the entered operation
* Validates numeric inputs
* Displays whole-number results without unnecessary decimal places

## How to Run

```bash
python src/calculator.py
```
